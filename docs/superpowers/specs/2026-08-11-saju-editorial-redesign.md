# SAJU ME Editorial Redesign

Date: 2026-08-11

## Direction
- Hanji editorial tone; Korean mysterious / hanok / mudang atmosphere
- Borrow from Cheongwoldang: hook copy, immersive reading — not marketplace UI
- Atmosphere only (no named character)

## Hero
- Full-bleed photo/illustration (`/hero-hanok.jpg`)
- Content: brand + title + one lead line only
- No orbs, keyword strips, floating badges

## Flow
- Idle: hero + form only (no Reading preview)
- Loading: ink-ring + rotating status copy + soft shimmer lines
- Result: document-style sections after response arrives

## Typography
- Subheads: serif, slight tracking, semibold
- Body: line-height ~1.9, slight tracking, ~46ch
- Sparse bold only for key phrases (via limited `**` in model output)

## Out of scope
- Product grids, review feeds, ranking banners, emoji-heavy UI
